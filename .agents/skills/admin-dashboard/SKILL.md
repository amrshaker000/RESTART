# Admin Dashboard & RBAC Skill

## Roles
- `super_admin`: Full system control, approvals, user management, site settings.
- `admin`: General operational management.
- `hr`: Registrations list, CSV exports, volunteer applications.
- `br`: Speakers and sponsors relationship management.
- `organizing`: Agenda timeline scheduling, live QR check-in gate.
- `media`: Website content editing, visual banners.

## Content Publishing Workflow
- `draft`: Created by team members.
- `pending_approval`: Submitted for Super Admin review.
- `published`: Approved and immediately visible on public website.
- `rejected`: Returned with revision comments.
