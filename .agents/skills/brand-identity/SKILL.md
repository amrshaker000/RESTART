# RESTART — Brand Identity Skill

## Art Direction
PLAYFUL DIGITAL NEO-BRUTALISM × MODERN GAMING × DIGITAL TECHNOLOGY

## Exact Color Palette
- **Navy**: `#0B1F44` (Primary dark, borders, main text)
- **Sky Blue**: `#7CCBFF` (Primary accent, primary buttons, highlights)
- **Light Blue**: `#E2F0FF` (Main page background)
- **Lavender**: `#B794F4` (Secondary accent, tags, decorative badges)
- **Soft Orange**: `#FF9F43` (Highlight accent, notification alerts)
- **White**: `#FFFFFF` (Card surfaces, clean contrast)

## Typography
- **Forever Freedom**: English display headings, hero typography (`.ttf`/`.otf`)
- **Madani Arabic**: Arabic display headings, RTL layouts
- **DM Sans / System UI**: Body and readable interface labels

## Logo Rules
- Never replace the logo with AI-generated alternatives.
- Use `banner-logo.png` for header navigation.
- Use `primary-logo.png` for hero and official tickets.
- Use `dark-banner-logo.png` for dark backgrounds (footer).
