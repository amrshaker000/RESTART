# Project Brief — RESTART

## Overview

RESTART is a Career Development Day organized by Resala Training Center (RTC). The website is a complete event platform combining promotion, registration, automated ticketing, QR check-in, and administration.

## Event Details

| Field | Value |
|---|---|
| Event Name | RESTART |
| Slogan | NO GAME OVER |
| Organizer | Resala Training Center (RTC) |
| Parent Org | Resala Charity Organization |
| Date | Friday, December 11, 2026 |
| Time | 09:00 AM – 04:00 PM (Tentative) |
| Attendance | 200–300 Guests |
| Speakers | ~10–15 |
| Venue | Not confirmed |

## Core Features

1. Modern event website (Neo-Brutalist design)
2. Online registration with duplicate protection
3. Automated personalized ticket generation (PDF + QR)
4. One-time QR-based check-in (atomic, database-level)
5. Interactive event agenda
6. Admin dashboard with 6 RBAC roles
7. Content approval workflow (Draft → Published)
8. Volunteer recruitment system
9. Email outbox with retry mechanism
