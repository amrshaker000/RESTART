# Brand Guidelines — RESTART

## Art Direction: PLAYFUL DIGITAL NEO-BRUTALISM

Combining: Neo-Brutalist UI + Modern Gaming + Digital Technology + Geometric Layouts + Bold Typography + Interactive Elements

## Color Palette

| Color | HEX | Role |
|---|---|---|
| Navy | #0B1F44 | Primary dark, borders, text |
| Sky Blue | #7CCBFF | Primary accent, buttons |
| Light Blue | #E2F0FF | Main backgrounds |
| Lavender | #B794F4 | Secondary accent |
| Soft Orange | #FF9F43 | Highlights |
| White | #FFFFFF | Surfaces |

Distribution: Light Blue/White 60%, Navy 25%, Sky Blue 10%, Lavender+Orange 5%

## Typography

- English Display: Forever Freedom (Regular, Italic, Outline)
- Arabic Display: Madani Arabic (Thin, Regular, Bold, Black)
- Body/UI: DM Sans (400-700)

## Logo Assets

6 variants: Banner Logo, Primary Logo, Primary Logo Icon, Dark Banner Logo, Dark Logo, Dark Logo Icon

Logo elements: Geometric R with upward arrow, orbit shape, orange plus, sparkle, RESTART wordmark, NO GAME OVER tagline with lavender bar

## Neo-Brutalist Rules

- Borders: 2-3px solid Navy
- Hard shadows: `box-shadow: 5px 5px 0px #0B1F44`
- Sharp corners (default), some rounded for special elements
- Layered composition
- Background patterns: grids, dots, pixel blocks
